# Architectural Decision Records

Formato basado en Richards & Ford, *Fundamentals of Software Architecture* (2.ª ed.), cap. 21.
Para una decisión nueva, copia [`0000-plantilla.md`](./0000-plantilla.md) con el siguiente número.

| ADR | Título | Estado |
| --- | --- | --- |
| [ADR-01](./0001-particionamiento-por-dominio.md) | Particionar el sistema por dominio del juego mediante un monolito modular | Proposed |
| [ADR-02](./0002-reglas-como-estrategias.md) | Implementar las reglas de victoria como estrategias intercambiables dentro del monolito modular | Proposed |

Un ADR aceptado no se edita: si la decisión cambia, se crea uno nuevo y el anterior pasa a *Superseded*.
